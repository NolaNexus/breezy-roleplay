# Breezy Roleplay Session Repository

This repository serves as a playground for running and documenting role‑play scenarios.  It is intended to be a light‑weight, reproducible environment where you can:

1. **Define scenarios** – Each scenario lives in `scenarios/` as a plain text or Markdown file.
2. **Record sessions** – Capture transcripts and artefacts under `sessions/`.
3. **Automate** – Use the development workflow scripts in `scripts/` to create new sessions, archives, or summaries.
4. **Collaborate** – Leverage the Git workflow: fork, issue‑track, and merge changes.

> This is only the initial scaffold; you can extend it with additional tooling, CI configurations, or formatters as needed.
